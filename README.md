# frontend

- Frontend: Parte de um site com a qual o usuário interage, como botões, menus, imagens e formulários.

- Cliente x Servidor: O cliente, geralmente o navegador, faz solicitações, enquanto o servidor processa essas solicitações e envia respostas.

- HTML: Define a estrutura e o conteúdo da página.

- CSS: Define a aparência da página, como cores, fontes e layouts.

- JavaScript: Adiciona interatividade e funcionalidades ao site.

- W3C: Organização internacional que desenvolve padrões e recomendações para tornar a Web mais acessível, consistente e compatível entre diferentes navegadores e dispositivos.
