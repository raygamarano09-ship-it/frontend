- <h1>: Define o título principal de uma página, geralmente o mais importante.

- <h2>: Define um subtítulo, usado para organizar as seções do conteúdo.

- <p>: Define um parágrafo, utilizado para escrever textos.

- <ul>: Cria uma lista não ordenada, que normalmente aparece com marcadores, como bolinhas.

- <ol>: Cria uma lista ordenada, que normalmente aparece com números.

- <li>: Define cada item de uma lista, sendo utilizado dentro das tags <ul> ou <ol>.
