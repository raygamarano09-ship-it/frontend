- index.html: É o arquivo principal do site, responsável por definir a estrutura e o conteúdo da página, como títulos, textos, botões, links e imagens.

- css/style.css: A pasta css armazena os arquivos de estilo, e o arquivo style.css define a aparência do site, como cores, fontes, tamanhos, espaçamentos e organização dos elementos.

- js/script.js: A pasta js armazena os arquivos JavaScript, e o arquivo script.js é responsável pelas funcionalidades e interações do site, como cliques em botões, animações e mensagens.

- img/: É a pasta utilizada para armazenar as imagens do projeto, como logotipos, banners, fotografias e ícones que serão utilizados nas páginas do site.
